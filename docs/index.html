◉Instant capture

Screenshots land in the notch the moment the file is written — dispatch-source dir watch plus a 0.6s clipboard poll for ⌃⇧⌘4 captures.

◉Drag anywhere

Thumbnails drag out as real file URLs — into Terminal (path), Finder, Slack, an email. Click copies file + image to the clipboard.

◉Drop to shelf

Drag images from any app onto the notch — it shelves them and puts them on the clipboard. File promises from browsers included.

◉Every display

Hugs the hardware notch on the MacBook, draws its own on externals. One panel per screen, rebuilt on plug/unplug, shows over fullscreen.

Native Swift, ~700 lines, no dependencies · github.com/CasterlyGit/ledge
